# Working Practices

- Remove any mannered prose from your answers

# Code Style

- Your comments must remain short. For example, if the name of an enum variant is enough to infer what it represents, do not add a comment. Avoid multi-line comments, especially if they narate the conversation or the iterations and do not add value to the code for future reference.
