# Human commit messages

Format: `<type>(<scope>): <subject>`, imperative, lowercase, no trailing
period, under 70 characters. Types: `feat`, `fix`, `refactor`, `perf`, `docs`,
`test`, `build`, `ci`, `chore`, `style`. Scope is the module or area touched
(`ai`, `eww`, `nvim`, `zsh`, `wt`), omitted when the change is repo-wide.

## Body

Default to no body. Add one only for something the diff cannot say: a
non-obvious why, a constraint, a trap the next reader would walk into. Two
lines is the ceiling; one is usually enough.

Never write:

- a list of the files or functions touched — `git show` already prints it
- a restatement of the diff in prose
- narration of the work ("first X, then Y", "now everything is consistent")
- justification of an obvious change ("this improves maintainability")
- `Co-Authored-By`, "Generated by", or any other AI marker

Reasoning that felt essential while writing the code is usually obvious in the
final state. If the body only makes sense next to the conversation that
produced it, drop it.

## Footer

Issue references only, on their own line: `Closes COD-1234`, `Refs #42`.

## Examples

```
fix(eww): leave a 2px gap between tiled windows and the bar
```

```
feat(ai): track omp config, regroup agent configs under ai/

Merge claude.nix and the omp links into one ai module, sharing ai/skills.
```

```
refactor(bar): format claude usage from omp instead of fetching it

The API route needs a token the bar has no way to refresh.
```

Same change, slop version — everything below the subject is already in the
diff, and the trailer serves nobody:

```
refactor(bar): format claude usage from omp instead of fetching it

This commit refactors the claude usage widget. Previously, the script
fetched the usage data from the API endpoint directly. Now it parses the
output of the omp CLI instead:

- update bar-scripts/claude-usage.sh to call omp
- remove the API token handling
- update modules/gui/eww/default.nix accordingly

This makes the code cleaner and easier to maintain.

Co-Authored-By: Claude <noreply@anthropic.com>
```
