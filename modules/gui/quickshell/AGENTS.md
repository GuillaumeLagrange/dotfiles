# quickshell bar

A port of the eww bar (`modules/gui/eww/`) to [quickshell](https://quickshell.org),
kept side by side with it while the two are compared.

## Layout

```
default.nix     The quickshell package (upstream flake input, not nixpkgs: it is
                newer and only the flake exposes `withModules`), the generated
                Config.qml, the assembled shell directory, and the user service.
qml/
  shell.qml     One Bar per entry in Quickshell.screens.
  Theme.qml     Singleton: gruvbox material palette, fonts, bar metrics.
  Config.qml    GENERATED by default.nix — absolute store paths and glyphs.
  components/   Pill, Tip (hover tooltip), PopupPanel + HoverGate (hover panels).
  services/     Singletons: Niri (the IPC tap), Sys (cpu/mem/disk), Claude,
                Media (mpris), Quick (idle/dnd/power profile), Recorder (IPC in).
  bar/          Bar.qml plus one file per widget.
  popups/       NowPlaying, Calendar, QuickSettings.
```

`niri-state` is shared with the eww bar: `default.nix` builds
`../eww/niri-state` and the QML reads its snapshot lines with a `SplitParser`.

## Running it

The unit is installed but **not** wanted by `graphical-session.target`, because
eww still owns the session and two bars would both claim an exclusive zone:

```bash
systemctl --user stop eww && systemctl --user start quickshell
journalctl --user -u quickshell -e     # QML errors land here
qs -c bar                              # or run it in the foreground
```

## Design

**What the port deleted.** Everything eww needed a script for, quickshell has a
service for: `Services.Pipewire` (volume), `Services.UPower` (battery, power
profiles), `Services.Mpris` (media), `Services.SystemTray` + `QsMenuAnchor`
(tray and its DBusMenu menus), `FileView` on procfs (cpu/memory). What survives
as a process is what genuinely is one: the niri tap, `df`, `claude-usage.sh`,
`makoctl`, and the held `systemd-inhibit` idle lock.

**Config.qml is generated, for the same reason the eww yuck was**: every binary
is an absolute store path, and every nerd-font glyph is decoded in Nix from a
JSON `\u` escape (`glyph "F0493"`, surrogate pairs handled) so no QML source
carries a private-use character that an edit could silently strip.

**Popups are hover-driven like eww's, but the machinery is gone.** eww needed
two runtime flag files and an mtime comparison because GTK fires hover-lost as
the pointer crosses a popup's child widgets; `HoverHandler` reports the whole
subtree, so `HoverGate` is a dwell timer plus a close debounce. `PopupPanel`
anchors above its trigger with `PopupAdjustment.SlideX`, so no panel needs a
hardcoded offset from the screen edge.

**The strip is drawn as siblings, not overlays.** The off-screen part of a
column is a scrim `Rectangle` with per-corner radii over the tile, rather than
eww's per-column CSS gradient; the rails are two 1px rectangles. Zero-width
spacers are free here — the `spacer` widget eww needed (a `:width 0` box is
still allocated a pixel in GTK) has no counterpart.

## Gotchas

- **A positioner's `implicitHeight` is read-only.** `Row`/`Column` compute it
  from their children, so children must not take their height from the row, and
  the row cannot be given one. Bar items size themselves from `Theme`.
- **In a `RowLayout`, a child whose implicit size depends on the layout's own
  size resolves to zero.** That is what emptied the left cluster: cells bound
  `implicitHeight` to the row, the row to the layout, the layout to the cells.
- **A panel of fill-width rows has no implicit width.** `PopupPanel.minContentWidth`
  is the floor eww wrote as a CSS `min-width`; the content item must also
  `anchors.fill: parent`, or it keeps its own narrow implicit width inside a
  wider panel.
- **`UPowerDevice.percentage` is a 0-1 fraction**, not 0-100 (`DBusDataTransform`
  multiplies the wire value by 0.01).
- **Filter `playerctld` out of `Mpris.players`** — it proxies whichever player is
  active, so the now-playing panel otherwise lists the same track twice.
- **Flakes only see git-tracked files.** A new QML file that is not `git add`-ed
  is missing from the assembled shell directory, and the bar fails to load with
  `Type X unavailable`.
- Singletons need `import QtQuick` for `Timer` and the `color` type; without it
  the whole shell fails to load with `color is not a type`.

## Testing

niri has no cursor-warp action and the winit backend takes its size from its
host window, so the bar is exercised in a **nested niri inside a headless cage**
— off screen, at a fixed size, with a real niri IPC socket:

```bash
env -u WAYLAND_DISPLAY -u NIRI_SOCKET WLR_BACKENDS=headless \
  cage -- niri --config /tmp/nested-niri.kdl
```

The nested niri must **not** get `--session` (it would import its environment
into the session's systemd manager — see the repo `AGENTS.md`), and it only
exports `NIRI_SOCKET` to what it spawns itself, so the bar has to be launched
from inside it with `NIRI_SOCKET` pointed at `/run/user/…/niri.$WAYLAND_DISPLAY.*.sock`.
Screenshot with `grim` from inside that session. Hover-driven panels cannot be
opened without a pointer: force `triggerHovered: true` in a throwaway copy of
the shell directory instead.
